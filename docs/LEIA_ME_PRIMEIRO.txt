PRANCHETA PRO - SIMULADOR TATICO INTERATIVO DE FUTEBOL
Entrega unica: codigo Java BlueJ + executavel JAR + documentacao + UML + exemplo JSON.

COMO ABRIR NO BLUEJ:
1. Extraia todo o ZIP em uma pasta do computador.
2. BlueJ > Projeto > Abrir Projeto > Prancheta_Tatica_Futebol_BlueJ.
3. Clique em Compilar.
4. Clique com o botao direito na classe Main > void main(String[] args).

COMO RODAR O EXECUTAVEL:
- Clique duas vezes em Prancheta_Tatica_Futebol.jar (Java instalado).
- Se nao abrir, no terminal: java -jar Prancheta_Tatica_Futebol.jar

VERIFIQUE O MANUAL em Documentacao_Pracheta_Tatica_Extensionista.docx.

FUNCOES PRINCIPAIS
- 22 titulares (11 por equipe), bola e campo proporcional.
- Formacoes: 4-3-3, 4-4-2, 4-2-3-1, 3-5-2, 3-4-3, 4-1-4-1,
  5-3-2, 4-5-1, 4-3-2-1, 3-4-2-1, 4-2-2-2, 4-1-2-1-2.
- Personalizacao de jogadores e equipes, banco e substituicoes.
- Ferramentas de passes, chutes, marcacoes, rotas e zonas de pressao.
- Jogos de bola parada, reproducao animada, desfazer.
- Salvar e abrir JSON; exportar imagem PNG.
- Teste automatico sem interface: classe TestesProjeto.

Requisitos extraidos do relatorio Extensionista Julio.pdf.
Preparado com bibliotecas padrao de Java 8+ (compilado com --release 8).

ATUALIZADO
- Melhor contraste de todos os botoes, sem depender de passar o mouse.
- Penalti, falta frontal e escanteio reposicionam jogadores e bola automaticamente.
- Ambos os times podem ser cobradores.
- Simulacao permite editar posicoes manualmente e salvar em JSON.
